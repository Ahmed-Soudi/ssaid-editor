# SSAID Editor

Android development utility for inspecting and editing user-selected ABX test fixtures.

## Planned features
- Search installed applications by label or package name.
- Edit value and defaultValue independently, without application-imposed length or hexadecimal validation.
- Parse and serialize ABX fixtures directly.
- Export edited copies and preserve original fixtures.
- Build debug APK using GitHub Actions.

This project scope excludes live system identity changes for third-party applications. No implementation or APK is included in this initial scope document.
